# Homework 15: Torque Wrench Design Project

## 5.1 The Baseline Design

### 5.1.1 Results

#### Part 1: Hand Calculations

The baseline design consists of a non-ratcheting, 3/8-inch-drive torque wrench rated for 600 in-lbf. The wrench is modeled as a cantilever beam with a rectangular cross-section, subjected to a transverse force at the end of the handle.

The objective is to determine the maximum normal stress and load-point deflection using analytical beam equations.

#### Given Parameters

| Parameter | Symbol | Value |
|---|---|---|
| Material | - | M42 Steel |
| Applied torque | T | 600 in-lbf |
| Handle length | L | 16 in |
| Width | h | 0.45 in |
| Thickness | b | 0.50 in |
| Young's modulus | E | 32,000,000 psi |
| Poisson's ratio | nu | 0.29 |

#### 1. Applied Force

The applied force is determined from the rated torque and the handle length.

<div style="text-align:center; padding:15px; background:#f5f6fa; border-radius:8px; margin:15px 0;">

T = F × L

F = T / L

F = 600 / 16

<strong>F = 37.5 lbf</strong>

</div>

#### 2. Maximum Normal Stress

The maximum bending moment occurs at the fixed end of the cantilever beam.

<div style="text-align:center; padding:15px; background:#f5f6fa; border-radius:8px; margin:15px 0;">

M_max = F × L

M_max = 37.5 × 16

<strong>M_max = 600 in-lbf</strong>

</div>

For a rectangular cross-section, the second moment of area is:

<div style="text-align:center; padding:15px; background:#f5f6fa; border-radius:8px; margin:15px 0;">

I = bh³ / 12

I = (0.50 × 0.45³) / 12

<strong>I = 0.0037969 in⁴</strong>

</div>

Using the flexure formula, the maximum normal stress is:

<div style="text-align:center; padding:15px; background:#f5f6fa; border-radius:8px; margin:15px 0;">

sigma_max = M_max × c / I

c = h / 2 = 0.225 in

sigma_max = (600 × 0.225) / 0.0037969

<strong>sigma_max = 35,556 psi = 35.56 ksi</strong>

</div>

#### 3. Load-Point Deflection

The load-point deflection is calculated using the cantilever beam deflection equation for an end load.

<div style="text-align:center; padding:15px; background:#f5f6fa; border-radius:8px; margin:15px 0;">

delta = FL³ / (3EI)

delta = (37.5 × 16³) / (3 × 32,000,000 × 0.0037969)

<strong>delta = 0.4214 in ≈ 0.421 in</strong>

</div>

#### Summary of Hand Calculation Results

| Parameter | Calculated Result |
|---|---|
| Applied force | 37.5 lbf |
| Maximum bending moment | 600 in-lbf |
| Second moment of area | 0.0037969 in⁴ |
| Maximum normal stress | 35.56 ksi |
| Load-point deflection | 0.421 in |

The calculated maximum normal stress and load-point deflection agree with the reference values provided in the assignment.

The baseline design does not satisfy the minimum deflection requirement of 1 inch at the rated torque of 600 in-lbf. Therefore, modifications to the material and/or geometry are necessary to improve the sensitivity of the torque wrench.
